# Art Brickwork Ltd – website

Static website for https://www.artbrickwork.co.uk, hosted on Cloudflare Pages.

- No build step: Cloudflare Pages build command = (none), output directory = `/`.
- Pages: Home, About Us, Services, Our Work, Contact (+ thank-you, 404).
- Quote form posts to FormSubmit (Artbrickwork@hotmail.com). The first submission sends an activation email that must be confirmed once.
- Project photos (assets/img/work-*.jpg): Art Brickwork Ltd's own photos from its Google Business Profile. Hero and detail close-ups: Unsplash (free licence).
